# 旅程目标预输入（临时功能）

在运行页的「旅程目标预检查」中填写角色、玩法、目标装备技能组合和训练方向，预检查并保存。脚本从目标组合自动确定所需装备和三月声援方向，页面显示只读的规划说明，无需填写开局装备类型或确认声援方向。保存不会启动或恢复脚本；运行中的目标只能在手动暂停或安全暂停后更改。

目标装备技能是腾讯表格中的 AX5（攻击＋暴击）等组合，不是旧技能库中的技能，也不是支援卡事件潜能。角色页列出的多个方案是可选方案，当前版本一次追踪一个组合。推荐尚未收录的角色可手动输入；不会按角色名猜测推荐。

## 来源与覆盖

- [角色推荐](https://docs.qq.com/sheet/DZkh2QmxKdnJUaVpw?tab=6chp1a)：已核对格温/克温、M教授、阿莫拉、克莉丝特的三种玩法与两种可选装备方案。
- [装备组合](https://docs.qq.com/sheet/DZkh2QmxKdnJUaVpw?tab=lzqghu)：AX 至 HX 各 8 个组合，以及 XX1/XX2/XX3 特殊技能，代码、材料、效果与来源单元格存于 `profiles/journey_targets.json`。
- 装备页图片的四组类型用于自动选择三月声援：攻击/暴击/爆伤对应攻击向，生命/防御/速度对应生存向，命中/抗性对应综合向，XX 特殊技能对应战术向。方向按目标组合的起始类型确定，例如 AX2（攻击＋生命）选择攻击向，BX1（生命＋攻击）选择生存向。普通训练仍支持攻击/生存两种策略，训练方向独立填写。
- FX8 的效果数值与组合名称存在不一致，保留原文并提示。材料依据组合名，不用该数值猜测。

## 脚本执行

目标保存在 Git 忽略的 `runtime/journey_target.json`，带独立版本和运行实例作用域。启动和每次页面调度前校验；暂停后保存的新版本在下一次继续时读取。首次加载本次代码需要使用「重启恢复」，旧进程不能热加载 Python 实现。

训练规则、普通事件评分和普通奖励的方向使用明确填写的训练方向。「训练的方向性」事件（三月声援）必须逐项核对四个声援选项文字，再按目标技能组合的声援分组选择；缺少目标、目录分组缺失、方向锁定或选项识别不完整时安全暂停。旧目标中的手动声援方向不会覆盖组合决策，决策日志记录自动方向的来源。

组合所需的起始装备是配方要求，不代表当前背包已拥有该装备。「已取得目标后续材料」只用于填写经人工核对的实际进度，默认未取得。

「实际携带配置」可以选填实际角色、旅程记录和支援卡，仅用于复盘记录；不从目标角色推断当前角色，也不影响策略。结算后可以在「旅程复盘记录」中补充未读出的最终属性、已装备技能和评鉴结果。留空表示未核对，列表明确填“无”表示没有携带或装备。详见 `docs/LOG_GUIDE.md`。

装备事件及奖励选择优先选目标缺少的后续材料。仅接受明确装备标签、组合代码或在装备上下文中唯一可辨认的属性行；图片、混合属性或多个相同候选无法唯一确认时暂停。不会把普通潜能或属性 buff 当装备材料。

选择装备前记录待确认状态，画面离开选择界面后才标记材料已获得。输入后异常或重启时存在未确认记录，必须人工核对现有材料并重新保存目标；不会重放旧点击。材料已齐后的多余装备处置、组合完成检查和自动合成尚未实现，遇到相关装备页面保持安全暂停。

决策依据、目标版本和材料进度进入运行状态、checkpoint 和日志。不需要 AI 在线；AI 接管仍遵守 `paused_safe` 协议。

## 本地 API

`GET /api/journey-target` 返回目录、已保存目标、预检查和生效状态；`POST /api/journey-target/precheck` 只校验不保存；`PUT /api/journey-target` 在未运行或暂停时保存。

验证包括离线目标与实际处理器测试、现有运行控制回归以及浏览器表单检查。真实游戏中的装备图片识别和完整目标组合达成仍需要实测。
