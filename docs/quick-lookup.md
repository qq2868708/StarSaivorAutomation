# 救援者 / 阿尔克那数据快查

WebUI 的“救援者 / 阿尔克那数据快查”用于建立角色面板、阿尔克那详情和旅程结束记录之间的对应关系。

1. 停止自动化，并将 StarSavior 保持在前台。
2. 打开救援者界面，点击“读取救援者并遍历可见角色”。扫描器先保存当前截图和 OCR，再点击 OCR 已确认的右侧可见角色行，逐一保存角色详情。它不会滚动列表、抢焦点或猜测不可见角色。
3. 打开阿尔克那卡片详情，点击“读取当前阿尔克那”。扫描器只读取当前详情页，不点击卡片或改变游戏状态。
4. 点击“生成对应关系”。结果写入被忽略的 `runtime/quick_lookup.json`，截图写入 `logs/screenshots/`。

对应规则保持语义边界：救援者名称可以映射到旅程记录的 `actual_setup.character`，阿尔克那详情可以映射到 `actual_setup.support_cards`；救援者详情里的等级、战力和属性是当前角色面板数据，不会写入旅程结束的 `outcome.final_stats`。卡名或角色无法唯一确认时保留 OCR、候选项和截图，并标为待人工确认。
