## 执行与验证边界

- 配置按目标显示第 1 至 N 个行动回合，不再用总调度次数或未经证实的全局 45 格定位。
- 目标与局部回合优先根据 HUD 月旬和距目标倒计时定位，明确的目标准备标题也可确认目标。
  目标清单里罗列的未完成目标不会被当作当前目标。
- 默认出现受理讨伐通知时优先讨伐，普通委托不执行；玩家可在全局及单个目标改变这些策略。
  “不执行”是过滤条件，不会被保底策略反向放行。不可用的参考行动会记录原因并选允许的行动。
- 主菜单区分明确“讨伐”入口/“受理讨伐”通知与未带该通知的“委托”入口，
  保存实际入口来源到 checkpoint，避免重启后把普通委托误当成通知讨伐。
- 新的普通委托设置与入口分派有离线回归覆盖，尚未开启新旅途实机验收；
  以上历史截图仅用于核对阶段和回合，不冒充新分派器的实机验收。
- 试听曾遇到旧服务 404，以及 Python 3.12 不存在 `winsound.SND_SYNC` 的实际兼容错误。
  本机播放改用 `SND_MEMORY` 的默认同步模式；浏览器试听也支持无需旧接口的 Web Audio 兜底。
  回归必须覆盖真实点击试听和 Python 3.12 的接口，而不只检查 WAV 文件头。

运行日志、原图和截图核验产物仍留在忽略目录，不纳入 Git。
